The idea

Every Object Begins With Coordinates.

A shape is a list of points. A matrix is a rule that sends every point somewhere new. Apply one rule to all the vertices and the whole object moves, turns or resizes together.

01

Represent

Store the vertices as columns: P = [[1, 4, 2], [1, 1, 3]] for A, B, C.

02

Transform

Apply a transformation such as P′ = MP or P′ = P + t.

03

Render

Draw the new vertices and connect them. The shape on screen is the shape in the math.

Homogeneous coordinates

Making translation a matrix multiplication.

Translation is an addition, but no 2 × 2 matrix can translate arbitrary points. Writing a point as (x, y, 1) lets a 3 × 3 matrix do it. The extra coordinate is a bookkeeping device, not a new spatial dimension. 2D affine transformations commonly use 3 × 3 matrices; 3D ones use 4 × 4.

Because the result is one matrix product, several transformations can be combined by multiplying their matrices first. This is how graphics pipelines apply a chain of operations to millions of vertices.

What to watch

    Advantages

    • Compact. One matrix describes a whole transformation.
    • Consistent. The same operation applies to every vertex.
    • Precise. Results are predictable and checkable.
    • Composable. Multiply matrices to chain transformations.

    Future scope

    • 3D transformations with 4 × 4 matrices
    • Skeletal animation and real-time rendering
    • Ray tracing and full graphics pipelines
    • Computer vision and robotics
    • Artificial intelligence, where linear algebra is the core language
